# LaunchKit AI

Independent product-content service prototype.

This project is isolated under `launchkit-ai/` on the `launchkit-ai` branch. It is not yet a live paid service. Deployment, secrets, AI API configuration, payment verification, privacy terms, and end-to-end testing remain required.

## Scope
- Customer product brief intake
- Order storage API
- AI-generated marketing content pack
- Operator review and manual payment verification

Never collect wallet seed phrases or private keys. Never treat screenshots as proof of payment.
